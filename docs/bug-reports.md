# Баг-репорты F-Bank

## BR-01. Сервис разрешает перевод отрицательной суммы

**Проект:** F-Bank  
**Компонент:** форма перевода денежных средств  
**Серьёзность:** Critical  
**Приоритет:** High  
**Окружение:** Google Chrome, локальный запуск через `python3 -m http.server 8000` из папки `dist`  
**Связанный тест-кейс:** TC-04  
**Автотест:** `test_negative_transfer_amount_is_rejected`

### Предусловия

Сервис открыт по адресу:

```text
http://localhost:8000/?balance=30000&reserved=20001
```

### Шаги воспроизведения

1. Нажать на счёт `Рубли`.
2. Ввести номер карты `1111111111111111`.
3. В поле суммы перевода ввести `-1000`.
4. Проверить доступность кнопки `Перевести`.

### Ожидаемый результат

Отрицательная сумма не должна приниматься. Кнопка `Перевести` не должна отображаться. Пользователь должен видеть сообщение об ошибке валидации суммы.

### Фактический результат

Кнопка `Перевести` отображается. Пользователь может инициировать перевод отрицательной суммы.

### Влияние на продукт

Дефект критичен для банковского сервиса: отрицательная сумма нарушает базовую бизнес-логику денежного перевода и может приводить к некорректным финансовым операциям.

### Рекомендация по исправлению

Добавить проверку, что сумма перевода является положительным числом:

```text
amount > 0
```

Если сумма меньше либо равна нулю, не рассчитывать комиссию и не показывать кнопку перевода.

## BR-02. Сервис запрещает перевод, когда сумма с комиссией ровно равна доступному остатку

**Проект:** F-Bank  
**Компонент:** проверка доступной суммы перед переводом  
**Серьёзность:** Major  
**Приоритет:** High  
**Окружение:** Google Chrome, локальный запуск через `python3 -m http.server 8000` из папки `dist`  
**Связанный тест-кейс:** TC-05  
**Автотест:** `test_transfer_equal_to_available_amount_is_allowed`

### Предусловия

Сервис открыт по адресу:

```text
http://localhost:8000/?balance=30000&reserved=20001
```

Доступный остаток рассчитывается по формуле:

```text
30000 - 20001 = 9999 ₽
```

### Шаги воспроизведения

1. Нажать на счёт `Рубли`.
2. Ввести номер карты `1111111111111111`.
3. В поле суммы перевода ввести `9099`.
4. Проверить доступность кнопки `Перевести`.

### Расчёт

Комиссия составляет 10% с округлением вниз:

```text
9099 / 100 = 90.99
floor(90.99) * 10 = 900 ₽
```

Итоговая сумма операции:

```text
9099 + 900 = 9999 ₽
```

Итоговая сумма операции ровно равна доступному остатку и не превышает его.

### Ожидаемый результат

Кнопка `Перевести` отображается, перевод доступен.

### Фактический результат

Кнопка `Перевести` не отображается. Вместо неё показывается сообщение `Недостаточно средств на счете`.

### Влияние на продукт

Пользователь не может перевести всю доступную сумму с учётом комиссии, хотя по требованиям перевод должен быть возможен, если итоговая сумма операции не превышает доступный остаток.

### Рекомендация по исправлению

В проверке доступности перевода использовать сравнение `>= 0`, а не `> 0`:

```text
balance - reserved - commission - amount >= 0
```
