# F-Bank: ручное и автоматизированное тестирование

Репозиторий подготовлен для задания по тестированию ненастоящего банковского онлайн-сервиса F-Bank.

## Структура проекта

```text
.
├── dist/
│   ├── index.html
│   └── assets/
├── docs/
│   ├── test-cases.md
│   └── bug-reports.md
├── tests/
│   └── test_fbank.py
├── .github/workflows/
│   └── selenium.yml
├── requirements.txt
└── README.md
```

## Локальный запуск сервиса

По инструкции к заданию сервис запускается из папки `dist`:

```bash
cd dist
python3 -m http.server 8000
```

После запуска открыть в браузере:

```text
http://localhost:8000/?balance=30000&reserved=20001
```

Параметры URL задают сумму на рублёвом счёте и резерв. Для тестирования используются неотрицательные числовые значения, при этом резерв не должен быть больше суммы на счёте.

## Локальный запуск автотестов

В отдельном терминале из корня репозитория:

```bash
pip install -r requirements.txt
BASE_URL=http://localhost:8000 pytest -q
```

## GitHub Actions

CI настроен в файле `.github/workflows/selenium.yml`. Workflow:

1. устанавливает Python и зависимости;
2. запускает локальный HTTP-сервер из папки `dist`;
3. запускает Selenium-тесты через `pytest`.

Сборка должна быть красной, потому что автотесты проверяют корректное ожидаемое поведение, а в текущей версии сервиса есть дефекты.

## Найденные дефекты

1. Сервис разрешает перевод отрицательной суммы.
2. Сервис запрещает перевод, когда сумма перевода вместе с комиссией ровно равна доступному остатку. По инструкции такой перевод должен быть разрешён, потому что сумма не превышает доступную.
